# Documentation index — Estadística

Every document in this repo, and the facts it is the authority for. When two of them seem to state the same thing,
the one named here wins and the other should link to it.

| Document | Mode | Reader | It is the authority for |
|---|---|---|---|
| [`../README.md`](../README.md) | how-to + reference | developer, operator | What the app is, its status, how to stand it up, its settings, and the traps it has paid for |
| [`manual.md`](manual.md) | how-to, **in Spanish** | staff, and whoever administers the app | How to use each view and the admin section, in the screens' own words |
| [`../CONTEXT.md`](../CONTEXT.md) | reference | everyone | **The vocabulary**: serie, fuente, consulta, pares, informante, meta comprometida, PIV… |
| [`adr/`](adr/) | explanation | developer | Each decision, and the reasoning that was live when it was taken (0001–0008, no gaps) |
| [`../ROADMAP.md`](../ROADMAP.md) | status | everyone | What is next and what is not planned |
| [`../BUGS.md`](../BUGS.md) | history | developer | What went wrong, why, and where the fix lives |
| [`../CHANGELOG.md`](../CHANGELOG.md) | history | operator | What changed, per version |
| [`../openapi.json`](../openapi.json) | reference (generated) | other apps | The OCS contract. Generated by `make openapi` from the controller, never edited by hand |
| [`../seeds/metas-2026.json`](../seeds/metas-2026.json) | reference (data) | whoever administers the app | The 2026 Metas Sanitarias as read from the OOTT, with the notes on what was read rather than copied |

The manual is Spanish because its reader is: it walks the screens, which are Spanish. Everything else here is
English, like the code.

Decisions that bind more than this app live in gestion, the trunk: which establishment an install serves is
[gestion ADR-0013](https://github.com/APS-Conecta/gestion/blob/main/docs/adr/0013-the-establishment-is-instance-configuration.md),
and the OCS surfaces every app publishes are listed in
[gestion `docs/CONTRACTS.md`](https://github.com/APS-Conecta/gestion/blob/main/docs/CONTRACTS.md).
